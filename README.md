# La carta de Jesús

Lista de regalos de Reyes con fotos, variantes, tallas y enlaces directos a las tiendas. Adaptada a móvil y ordenador.

## Actualizar la lista

Los artículos están en `regalos.json`. Para añadir uno, copia un objeto existente y cambia su identificador, nombre, marca, categoría, detalle, tienda, enlace e imagen.

Una talla sin confirmar se guarda como `null`. Sustitúyela por la talla elegida entre comillas cuando Jesús la confirme. `requiereTalla: false` corresponde a artículos que no necesitan talla.

Las dos sudaderas Tommy son variantes distintas: VLP y Z00. Sus enlaces se conservan por separado.

## Publicación

Esta carpeta contiene la web lista para GitHub Pages, sin compilación ni instalación de dependencias. En la configuración de Pages se publica desde la rama `main` y la carpeta raíz `/`. Los cambios se hacen visibles cuando termina la publicación de GitHub.

Las fotos proceden de las tiendas. Los enlaces de compra siguen funcionando aunque una tienda deje de mostrar su foto. No se muestran precios ni disponibilidad.

La web no permite reservas ni registra quién compra un regalo. Las compras se realizan en la tienda enlazada.
